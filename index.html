How to Use DuplicateDeleter

1

Choose Folders

Open the app and click the "Add Folder" button. Add all the directories you want to scan. You can add as many as you like!

2

Timer or Manual

Click "Check Now" for an instant scan, or configure the Auto-Cull Frequency (e.g., every 10 minutes) to let the app work automatically in the background.

3

Merge or Ignore

Move discovered duplicates directly to the system trash with "Merge". Click "Ignore" if you want to keep a specific file duplicate on purpose.

Important on First Launch:

  • macOS: On your very first launch, *right-click* the app icon and select "Open" to bypass the unidentified developer warning safely.
  • Windows: The app is a portable `.exe` file. There is no installation required; you can run it directly from anywhere!

Behind the Scenes

Discover how DuplicateDeleter makes smart, secure decisions in the background to protect your data and save storage space.

Unique Fingerprints (MD5 Hashing)

Basic duplicate finders only compare file names, which can be inaccurate and risky. DuplicateDeleter reads the actual contents of each file in small chunks and calculates a unique cryptographic hash (a digital fingerprint). Two files with different names but identical contents will always be successfully detected.

Persistent JSON Memory

To ensure you don't have to re-add your monitored folders every time you open the app, it saves a tiny configuration file in your home directory: DuplicateDeleter_config.json. This securely stores your folder list and your ignored file hashes so they are remembered forever.

No Accidental Hard Deletion

We value safety over everything. When you choose to "Merge", the app utilizes the send2trash library. Files are never hard-deleted directly. Instead, they are moved to the official system Trash/Recycle Bin, meaning you can easily restore them if you change your mind.
